# Google Indexing — Problem Log & Fix Plan

Source: Google Search Console export, 2026-06-01.
Sitemap submitted: `https://utiltoolkits.com/sitemap.xml` (generated by [app/sitemap.ts](app/sitemap.ts)).
Snapshot: **135 not indexed / 53 indexed**, indexed count dropping since March while impressions doubled (~100 → ~200/day).

This document is the master tracker. Future sessions: pick the next unchecked item, fix it, mark it done, commit. Do not delete completed items — keep them as a changelog.

---

## Diagnosis summary (from GSC Critical Issues)

| Reason                                       | Source         | Pages | Severity |
| -------------------------------------------- | -------------- | ----- | -------- |
| Crawled - currently not indexed              | Google systems | 72    | HIGH     |
| Discovered – currently not indexed           | Google systems | 52    | HIGH     |
| Not found (404)                              | Website        | 10    | HIGH     |
| Soft 404                                     | Website        | 1     | MED      |
| Page with redirect                           | Website        | 0     | —        |
| Alternative page with proper canonical tag   | Website        | 0     | —        |

Root causes (in order of impact):
1. **Thin / near-duplicate tool pages** — same shell, near-identical `<title>`, meta, H1, intro copy across ~94 tools → "Crawled, not indexed".
2. **Stale sitemap entries** — 10× 404 + 1 soft-404 emitted from auto-generated sitemap → trust damage.
3. **Low per-page authority/value signals** — no FAQ, no examples, no internal cross-links between related tools → "Discovered, not indexed".
4. **Site newness** — limited backlinks; Google indexes conservatively.
